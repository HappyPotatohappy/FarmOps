# GitHub 다운로드 재현 검증

검증일: 2026-10-01. FarmOps에 올릴 Git 인덱스에서 `git archive`로 ZIP을 만든 뒤 별도 폴더에 압축을 풀었습니다. 개발 폴더의 가상환경·실행 DB·TiRex 체크포인트는 포함하지 않았습니다. 이 소스에서 Docker 이미지를 새로 빌드하고 빈 볼륨으로 실행했습니다.

## 실제 실행 결과

| 검사 | 결과 |
|---|---|
| Docker 전체 백엔드 회귀 | 430 통과, 선택적 Chronos 검사 1 생략, 기존 Pydantic 경고 4건 |
| 소스 패키지·화면 회귀 | 패키지 21 통과, 실제 체크포인트 검사 1 제외; 화면 105 통과 |
| Git ZIP 파일 무결성 | `FILE_MANIFEST.json`의 모든 파일 SHA-256 일치 |
| Windows 방식 Git 체크아웃 | `core.autocrlf=true`에서 CSV 원본 바이트 및 실행 스크립트 LF 유지 |
| Linux ARM64 | 공개 벌통 3개 각각 168시간 예측, 공통 모델 v9, 문서·PDF·CSV ZIP 접근 성공 |
| Linux AMD64 | 빈 볼륨 초기화, 1시간·168시간 예측, 채밀 추천 성공 |
| 공식 모델 설치 | 고정된 TiRex-2 체크포인트 380,613,375바이트 다운로드 및 SHA-256 검증 성공 |
| 고온 자료 저장·재학습 | ARM64에서 v9→v10→v11, AMD64에서 v9→v10; 작업마다 LSTM 8회 학습 및 결합 가중치 계산 |
| 학습의 실제 반영 | LSTM 파라미터 해시 변경, TiRex-2 해시 유지, 적용된 새 버전으로 기존 벌통 예측 성공 |
| 반복 실행 | 고온 자료 504행 중복 저장 없이 새 작업과 새 모델 버전 생성 |
| 컨테이너 재시작 | v11, 재학습 작업 2건, 관측 504행 유지; 168시간 예측 재실행 성공 |

원본 결과: [ARM64 실행](git_download_arm64.json), [AMD64 실행](git_download_amd64.json), [재시작](git_download_restart.json).

ARM64와 AMD64 모두 Apple Silicon Mac의 Docker Desktop에서 실행했습니다. AMD64는 에뮬레이션이며 Windows 실기기 실행 결과는 아닙니다. Windows에서는 WSL 2 기반 Linux 컨테이너를 사용합니다.

## 다운로드 검사에서 보완한 사항

- MLflow의 기본 `./mlruns` 경로를 쓰기 가능한 실행 볼륨에 연결했습니다. 새 Git ZIP에 개발자의 임시 폴더가 없어도 시작되며, 기존 볼륨에도 필요한 폴더를 준비합니다.
- 출처 검증에 쓰는 CSV는 `.gitattributes`에서 줄바꿈 변환을 제외했습니다. Windows 체크아웃에서도 원본 SHA-256이 유지됩니다.
- 초기 MLflow SQLite의 빈 페이지에 남았던 개인 경로를 제거했습니다. 전후 SQL 내용은 동일하고 SQLite 무결성 검사도 통과했습니다.
- 테스트마다 임시 저장소를 사용하도록 구성해 실제 Docker 실행 환경의 관측·모델이 단위 테스트에 섞이지 않게 했습니다.
- 비동기 업로드 테스트는 완료 상태를 최대 30초까지 기다립니다. Docker 부하로 기존 5초를 넘는 경우에도 실제 완료·실패 상태를 검증하며, 완료되면 즉시 반환합니다.

전체 기능 회귀와 화면 검사 결과는 [검증 기록](RESULTS.md)에 있습니다. GitHub Actions는 별도의 소스·패키지·화면 검사이며 실제 모델 추론은 위 Docker 검증으로 확인했습니다.

이 기록은 실행 재현성을 검증합니다. 반복 합성 자료의 학습 수치를 실제 양봉장의 미래 예측 정확도로 해석하지 않습니다.
