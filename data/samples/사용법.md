# BeeOPS 공개 CSV — 현재 공통 앙상블로 예측하기

이 폴더는 공개 벌통 관측을 BeeOPS의 시간별 입력 형식으로 가공한 CSV와 출처 기록을 담고 있습니다. 현재 제품은 모든 벌통에 **같은 TiRex-2 + LSTM 앙상블**을 적용합니다. 벌통을 바꾸면 입력 관측이 달라집니다. 현재 적용 버전·run ID·결합 비율은 **사용 모델과 평가** 화면에서 확인합니다. 예전 공통 LSTM 버전을 선택하거나 별도 배포 차단 후보를 비교하는 안내는 현재 화면에 적용하지 않습니다.

## 파일 선택과 업로드

최종본을 처음 실행하면 공개 사례 3개가 이미 표시됩니다. 아래 파일은 추가 업로드용이며, 화면의 기본 공개 사례 목록과는 구분됩니다. **데이터 → CSV 파일 선택**에서 이 폴더의 파일을 직접 고르면 됩니다.

1. `http://localhost:8012`에서 **데이터** 화면을 엽니다.
2. CSV 파일을 선택하고 미리보기의 벌통 ID, 관측 기간, 신규·중복·충돌 행 수를 확인합니다. 미리보기만으로 저장되지는 않습니다.
3. **확인하고 저장 · 분석 시작**을 눌러 저장합니다. 같은 벌통 ID는 같은 원장에 연결됩니다. 이미 저장한 동일 관측은 중복 처리하고, 같은 시각의 다른 값은 덮어쓰지 않습니다.
4. 처리가 끝나면 해당 벌통을 선택하고 대시보드의 관측, 과거 예측 비교, 다음 1시간 예측, 향후 7일 예측과 채밀 후보를 확인합니다. 유효한 연속 입력이 부족하거나 추론에 실패하면 해당 사유를 확인합니다.
5. 현재 공통 모델의 구성은 **사용 모델과 평가**, 온도 감시와 실제 재학습 상태는 **운영과 작업 기록**에서 확인합니다.

| 파일 | 관측 수 | 용도 |
|---|---:|---|
| `ufc_meliponini_s3_initial.csv` | 672 | ① 약 6kg 무침벌의 초기 관측 |
| `ufc_meliponini_s3_followup.csv` | 241 | ② 같은 벌통에 이어지는 새 관측 |
| `ufc_meliponini_s3.csv` | 913 | ①+②를 한 번에 등록 |
| `vecauce_2021_3.csv` | 625 | 라트비아 84–110kg 벌통 입력 |
| `ufc_apis_1.csv` | 174 | 브라질 Apis 1의 28–30kg 벌통 입력 |

새 작업공간에서 무침벌 ①→② 순서로 저장하면 관측 추가에 따른 예측 변화를 확인할 수 있습니다. 전체 913행을 먼저 등록했다면 두 단계 파일 모두 중복입니다. 두 파일의 `hive_id`는 같은 `ufc_meliponini_s3`이며 시연을 위해 다른 ID로 바꾸지 않습니다.

**후속 241행만 이미 저장한 작업공간**에는 앞선 672행을 일반 업로드로 나중에 끼워 넣을 수 없습니다. 원장을 삭제하거나 ID를 바꾸지 말고 현재 저장된 관측으로 확인하세요. 처음부터 ①→②를 재현하려면 별도의 빈 실행 환경을 사용합니다. 기본 고온 실습의 검증된 기준 복구 예외는 이 공개 CSV에 적용되지 않습니다.

## 예측·MAE·재학습을 읽는 방법

대시보드는 현재 공통 모델로 최근 168시간의 무게·외기온을 읽어 앞으로 최대 168시간을 예측합니다. 다음 1시간 값은 이 미래 경로의 첫 값입니다. 채밀 후보는 같은 예측 경로에서 계산합니다. CSV를 올렸다는 이유만으로 예측이 정확해지거나 모델이 즉시 학습되는 것은 아닙니다.

무침벌 초기 파일의 마지막 관측은 **2025-11-25 16:00**, 다음 예측 대상은 **2025-11-25 17:00**입니다. 후속 파일까지 저장하면 마지막 관측은 **2025-12-05 17:00**, 다음 대상은 **2025-12-05 18:00**입니다. 이 시각은 아래 설명한 시스템 표기 기준입니다.

상단의 **모델 평가 MAE · 1시간**은 현재 모델에 저장된 평가 기록입니다. 과거 관측 차트의 비교 MAE는 현재 모델로 해당 벌통의 과거 1시간 예측을 다시 계산한 값입니다. 둘은 평가 자료와 목적이 다르며, MAE는 `평균(|실제값 − 예측값|)`의 kg 값입니다. 표본 수·구간을 함께 읽고 학습에 이미 쓰였을 수 있는 회고적 결과를 독립적인 미래 성능으로 해석하지 않습니다. 1시간 평가를 7일 정확도로 확대하지 않습니다.

일반 업로드 후에는 온도 분포를 확인하며 조건과 학습 자료가 충족될 때 자동 재학습을 요청합니다. 운영 화면의 **앙상블 재학습**으로도 요청할 수 있습니다. 실제 학습은 LSTM 파라미터와 결합 비율을 갱신하고 TiRex-2 체크포인트를 유지합니다. 같은 관측 스냅샷이나 이미 소비한 학습 목표는 일반 경로에서 반복 학습하지 않습니다. 완료한 새 공통 모델은 모든 벌통에 적용되며 성능 향상을 보장하지 않습니다.

## 출처와 가공

- 브라질: Santos 외, *Hive Monitoring (Apis mellifera and Stingless Bees) and Rainfall Data — UFC*, [Zenodo, DOI 10.5281/zenodo.20399470](https://zenodo.org/records/20399470), CC BY 4.0. `DadosMeliponas.csv` 센서 3과 `dadosColmeia1Apis.csv`를 사용했습니다.
- 라트비아: Zacepins, A.; Komasilova, O.; Komasilovs, V. (2025), *Bee colony monitoring data in Vecauce, Latvia, summer 2021*, [DataverseLV, DOI 10.71782/DATA/J1CQTJ](https://dv.dataverse.lv/dataset.xhtml?persistentId=doi:10.71782/DATA/J1CQTJ), V1, CC BY 4.0. 원본 5개 중 연속 관측이 가장 긴 `Vecauce2021_3.csv`를 사용했습니다.
- 원본 무게 kg와 **외기 온도** °C를 사용합니다. 유효한 행의 `[h,h+1)` 중앙값을 구간 종료 시각 `h+1`에 붙였습니다. 결측 보간·무게 상수 추가·배율 변경은 하지 않았습니다.
- 원본 시간대는 미상입니다. `+00:00`과 화면의 UTC는 시스템 입력용 표기 가정이며 실제 UTC 취득을 확인한 것이 아닙니다.
- 구간은 모델 점수가 아닌 관측 연속성과 고정 품질 규칙으로 골랐습니다. UFC는 연속 정상 구간, 라트비아는 1kg 초과 급변 1개를 포함한 연속 구간입니다. `colony_alert`는 숫자상 표시이며 분봉·채밀 등 원인을 확정하지 않습니다.
- 전체 원본을 대표하는 무작위 표본이 아닙니다. 공개 출처·저자·라이선스를 유지하고, 재배포할 때 시간별 집계·필터·구간 선택이라는 가공 내용을 함께 표시합니다. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)을 따릅니다.

각 CSV와 이름이 같은 `.provenance.json`에서 원본·가공 파일의 체크섬, 선정·필터·라이선스·시간대 가정을 확인할 수 있습니다. 일부 화면 설명은 자료 내보내기 당시의 기록이므로 현재 모델 사용법은 이 안내와 `docs/BeeOPS_모델_상세설명.md`를 기준으로 읽습니다. 원천 전체 파일과 과거 벤치마크의 비교 모델 산출물은 이 최종본에 포함되지 않습니다. 원본을 다시 확인하려면 provenance에 기록된 공식 출처와 체크섬을 이용합니다. 포함된 선택 연구 도구와 필요한 외부 입력은 [도구별 설명](../../scripts/README.md)에 정리했습니다.
